# AKWAYA COUNCIL - GUIDE FOR MR OKUMO

## To change the Mayor (Mayor is not for life)
1. Open content/mayor.json
2. Change name, title, message
3. Replace images/mayor.jpg with new photo (same name)
4. Commit. Site updates.

## To add news
Edit content/news.json

## To test in VS Code
1. Open folder akwaya-council-starter in VS Code
2. Install Live Server extension
3. Right-click index.html > Open with Live Server
